# Mairie d'Aubers - Réservations

Ce projet contient une page de connexion et une page de réservation pour la Mairie d'Aubers.

## Fichiers

- `index.html` : page d'accueil qui redirige vers `login.html`
- `login.html` : page de connexion
- `reservation.html` : page des réservations
- `mairie-Aubers.html` : ancien chemin de redirection depuis l'ancienne URL

## Utilisation

Ouvrez `index.html` dans un navigateur pour lancer le site.
